# Data license and attribution

This repository does **not** contain the raw MSM dataset.

Original dataset: *Multi-sensor and MTConnect dataset of metal cutting anomaly in milling from laboratory and industry settings*,
Kim, E., Sim, Y., Li, A. S., et al. (2026), Scientific Data, article s41597-026-07255-7
(https://doi.org/10.1038/s41597-026-07255-7). Data files: https://doi.org/10.34740/kaggle/ds/8392825.

The data files are released by their authors under CC BY 4.0 (verify on the Kaggle page before redistributing). The 2,508 path-level
records used here are derived from that dataset; the derived table `master_cutting_paths_CLEAN.csv` is not included because the
preprocessing that builds it from the raw release is not part of this repository.

The MIT license in `LICENSE` covers the code in this repository only. The manuscript and any publisher figures are subject to their own terms.
